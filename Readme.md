Formally Verified Banking Transaction System

 Overview

This project aims to develop a simplified banking transaction system that supports deposits, withdrawals, and transfers between multiple bank accounts.

The main goal is to ensure the correctness and reliability of financial transactions by verifying important properties and preventing logical errors.

Objectives

- Implement basic banking operations.
- Ensure account balances never become negative.
- Verify correct deposit and withdrawal operations.
- Ensure no money is created or lost during transfers.
- Prevent invalid transactions.
